# Глава 2. Значения, типы и управление выполнением

## Зачем тебе нужна эта тема

Любая программа хранит значения и решает, какие действия выполнить. В MATLAB тип многих переменных долго остаётся незаметным: обычное число чаще всего является `double`, а размер массива можно изменить во время работы. В C++ тип записывается явно и определяет:

- какие значения допустимы;
- сколько примерно памяти занимает объект;
- какие операции над ним разрешены;
- как выполняется арифметика;
- какие ошибки компилятор сможет обнаружить заранее.

Условные операторы и циклы тебе уже знакомы по MATLAB, но синтаксис и некоторые правила отличаются. Самые опасные различия — целочисленное деление, индексация с нуля, оператор `^`, преобразования типов и границы циклов.

Эта глава даёт базовый язык, достаточный для небольших расчётных программ. Функции и контейнеры появятся позднее; пока цель — уверенно работать со скалярными значениями и потоком выполнения.

## Результаты обучения

После главы ты сможешь:

- объявлять и инициализировать переменные основных типов;
- выбирать между `int`, `double`, `bool`, `char` и строкой;
- применять `const`;
- понимать числовые литералы и целочисленное деление;
- замечать опасные неявные преобразования;
- использовать `if`, `else if`, `else`;
- записывать составные логические условия;
- применять `switch` вместе с `enum class`;
- писать циклы `for` и `while`;
- выбирать правильные границы цикла;
- читать простой ввод и проверять его состояние;
- отличать синтаксически правильную программу от логически правильной.

## 1. Объект, значение и тип

Объявление переменной:

```cpp
double temperature{21.5};
```

Здесь:

- `temperature` — имя объекта;
- `double` — его тип;
- `21.5` — начальное значение;
- фигурные скобки выполняют инициализацию.

Тип не меняется во время жизни объекта:

```cpp
int count{10};
count = 12;       // можно: новое значение того же типа
// count = "ten"; // нельзя: строка не является int
```

Это одно из главных отличий от динамически используемого workspace MATLAB. Компилятор знает тип `count` ещё до запуска программы.

## 2. Основные типы

### `bool`

Хранит логическое значение:

```cpp
bool isReady{true};
bool hasError{false};
```

Используй `bool` для факта, на который можно ответить «да» или «нет».

### Целые числа

```cpp
int frameNumber{7};
int difference{-3};
```

`int` — хороший обычный выбор для небольших целых величин. У него ограниченный диапазон. Не предполагай, что любое математическое целое поместится в `int`.

Есть беззнаковые типы, например `unsigned int`. Они не хранят отрицательные значения, но это не делает их автоматически безопаснее. Вычитание ниже нуля приводит к переходу к большому положительному значению.

### Вещественные числа

```cpp
double frequency{1800.0};
double gain{0.75};
```

Для большинства учебных и инженерных расчётов выбирай `double`, если нет явной причины использовать `float`.

### Символ

```cpp
char grade{'A'};
```

Одинарные кавычки задают один символ. Двойные кавычки задают строковый литерал:

```cpp
char letter{'A'};
const char* text{"A"}; // другой тип; указатели будут изучаться позднее
```

Для обычного владеющего текста используй `std::string`:

```cpp
#include <string>

std::string name{"receiver"};
```

Подробная работа со строками будет позже, но уже сейчас важно различать символ и текст.

## 3. Инициализируй переменную сразу

Предпочитай:

```cpp
int attempts{0};
double total{0.0};
bool found{false};
```

Опасный вариант:

```cpp
int attempts;
// значение attempts не задано
```

Чтение неинициализированной локальной переменной фундаментального типа приводит к неопределённому поведению. Программа может иногда выглядеть рабочей, а затем выдавать случайный результат.

Фигурная инициализация помогает обнаруживать сужение:

```cpp
double precise{3.75};
// int truncated{precise}; // компилятор должен отклонить сужение
```

Если преобразование действительно нужно, запиши намерение явно:

```cpp
int truncated{static_cast<int>(precise)};
```

Результат будет `3`, а не `4`: дробная часть отбрасывается.

## 4. `const`: значение не должно меняться

```cpp
const double samplingRate{48000.0};
const int symbolsPerSlot{14};
```

Константа обязана получить значение при создании. После этого обычное присваивание запрещено.

Используй `const`, если переменная после вычисления не должна меняться. Это:

- выражает намерение;
- предотвращает случайное присваивание;
- упрощает чтение кода.

Не каждое значение обязано быть `const`. Счётчик цикла закономерно меняется.

## 5. `auto`: вывод типа, а не отсутствие типа

```cpp
const auto answer{42};       // int
const auto threshold{0.75};  // double
```

`auto` просит компилятор вывести тип из инициализатора. Тип всё равно существует и остаётся фиксированным.

Используй `auto`, когда тип очевиден из правой части или очень длинен. Для первых численных программ явные `int` и `double` часто полезнее: они заставляют тебя видеть арифметику.

Опасная ошибка ожиданий:

```cpp
const auto ratio{1 / 2}; // тип int, значение 0
```

`auto` не превращает целое деление в вещественное.

## 6. Числовые литералы и арифметика

```cpp
42      // int
42.0    // double
0.5     // double
2.0f    // float
```

Операторы:

```cpp
a + b;
a - b;
a * b;
a / b;
a % b; // остаток для целых типов
```

### Целочисленное деление

```cpp
const int integerResult{5 / 2};       // 2
const double stillTwo{5 / 2};         // сначала 2, затем 2.0
const double correct{5.0 / 2.0};      // 2.5
```

Тип переменной слева не меняет уже выполненную операцию справа.

### Возведение в степень

В MATLAB `^` означает степень или матричную степень. В C++ `^` — побитовый XOR для целых типов.

Для вещественной степени используй `std::pow`:

```cpp
#include <cmath>

const double areaScale{std::pow(3.0, 2.0)};
```

Для квадрата простое `value * value` обычно яснее.

### Составные присваивания

```cpp
total += value;
count += 1;
gain *= 2.0;
```

`count++` увеличивает число на единицу. Не помещай несколько изменений одной переменной в сложное выражение: ясный отдельный шаг проще проверять.

## 7. Сравнения и логика

Операторы сравнения:

```cpp
a == b; // равно
a != b; // не равно
a < b;
a <= b;
a > b;
a >= b;
```

Не путай присваивание и равенство:

```cpp
value = 5;   // присвоить
value == 5;  // сравнить
```

Логические операторы:

```cpp
conditionA && conditionB; // И
conditionA || conditionB; // ИЛИ
!conditionA;              // НЕ
```

`&&` и `||` вычисляются слева направо и используют короткое замыкание. Если результат уже известен, правая часть не выполняется:

```cpp
if (divisor != 0 && numerator / divisor > 2) {
    // деление выполняется только при ненулевом divisor
}
```

Побитовые `&` и `|` — другие операторы. Не используй их вместо логических `&&` и `||`.

### Цепочки сравнений

MATLAB-подобная математическая запись не переносится напрямую:

```cpp
// Неправильное намерение:
// 0.0 <= value <= 1.0
```

C++ сначала вычислит `0.0 <= value`, получит `bool`, а затем сравнит его с `1.0`. Пиши явно:

```cpp
0.0 <= value && value <= 1.0
```

## 8. `if`, `else if`, `else`

```cpp
if (temperature < 0.0) {
    std::cout << "frost\n";
} else if (temperature > 30.0) {
    std::cout << "hot\n";
} else {
    std::cout << "moderate\n";
}
```

Условие должно давать одно логическое решение. Стандартный контейнер целиком нельзя использовать как MATLAB-массив логических условий.

Даже для одной инструкции полезно писать фигурные скобки. Они уменьшают риск ошибки при последующем добавлении строки.

Опасный лишний символ:

```cpp
if (temperature < 0.0); { // ; завершает пустой if
    std::cout << "this block always runs\n";
}
```

## 9. `enum class` и `switch`

Когда значение выбирается из небольшого именованного набора, лучше выразить это типом:

```cpp
enum class Mode {
    idle,
    receive,
    transmit
};
```

Использование:

```cpp
Mode mode{Mode::receive};
```

`switch` удобно обрабатывает варианты:

```cpp
switch (mode) {
case Mode::idle:
    std::cout << "idle\n";
    break;
case Mode::receive:
    std::cout << "receiving\n";
    break;
case Mode::transmit:
    std::cout << "transmitting\n";
    break;
}
```

`break` завершает текущую ветвь. Если его забыть, выполнение перейдёт в следующую ветвь. Иногда это делают намеренно, но новичку лучше всегда выражать такое намерение явно и не полагаться на случайное проваливание.

Преимущество `enum class` перед числами `0`, `1`, `2`: имя типа и вариантов несёт смысл, а компилятор не смешивает значение режима с произвольным целым.

## 10. Цикл `for`

Классический цикл:

```cpp
for (int index{0}; index < 5; ++index) {
    std::cout << index << '\n';
}
```

Он состоит из трёх частей:

1. `int index{0}` — выполняется один раз;
2. `index < 5` — проверяется перед каждой итерацией;
3. `++index` — выполняется после тела.

Будут выведены числа `0`, `1`, `2`, `3`, `4`.

Полуоткрытый диапазон `[0, count)` очень распространён в C++:

- начало включено;
- конец не включён;
- количество итераций равно `count`;
- условие естественно сочетается с нулевой индексацией.

Не используй `<= count`, если `count` — число элементов. Это даст лишнюю итерацию.

## 11. Цикл `while`

`while` подходит, когда заранее неизвестно точное число повторений:

```cpp
int attempts{0};
bool connected{false};

while (!connected && attempts < 3) {
    ++attempts;
    // попытка соединения
}
```

Перед написанием `while` ответь:

- какое условие завершает цикл;
- что меняется на каждой итерации;
- может ли условие никогда не стать ложным.

Бесконечный цикл может быть намеренным в сервере или обработчике событий, но в обычной учебной задаче чаще указывает на забытое изменение состояния.

## 12. Вложенные циклы

```cpp
for (int row{0}; row < 3; ++row) {
    for (int column{0}; column < 4; ++column) {
        std::cout << '(' << row << ", " << column << ")\n";
    }
}
```

Внутренний цикл полностью выполняется для каждого значения внешнего. Число итераций здесь равно `3 * 4`.

Вложенные циклы естественны для сеток и матриц, но порядок обхода нужно понимать. Позднее он будет связан с расположением данных в памяти.

## 13. Область видимости

Имя, объявленное внутри блока, существует только в этом блоке:

```cpp
if (true) {
    const int localValue{7};
    std::cout << localValue << '\n';
}

// localValue здесь недоступно
```

Счётчик, объявленный в заголовке `for`, тоже недоступен после цикла:

```cpp
for (int index{0}; index < 3; ++index) {
    // index доступен здесь
}
// index здесь не существует
```

Создавай переменную в минимальной области, где она нужна. Это уменьшает число состояний, за которыми приходится следить.

## 14. Простой ввод и его проверка

```cpp
double value{0.0};
std::cout << "Enter a number: ";

if (!(std::cin >> value)) {
    std::cerr << "Invalid input\n";
    return 1;
}
```

`std::cin >> value` пытается прочитать значение нужного типа. В логическом контексте результат сообщает, успешен ли ввод.

Не используй переменную как будто ввод удался, если состояние потока не проверено.

`std::cerr` — стандартный поток для сообщений об ошибках. Код возврата `1` сообщает о неуспешном завершении.

Полноценное восстановление потока после неверного ввода будет изучаться позже. На первом этапе допустимо завершить программу с понятным сообщением.

## 15. Отличия от MATLAB

### Обычное число не всегда `double`

Литерал `2` является целым, а `2.0` — вещественным. Это влияет на деление.

### Тип переменной фиксирован

После `int count{3};` переменная `count` не может позже стать строкой или матрицей.

### Индексация и циклы начинаются с нуля

Диапазон `for (int i{0}; i < count; ++i)` соответствует `count` итерациям с индексами от нуля.

### `^` не является степенью

Это побитовый XOR. Используй умножение для квадрата или `std::pow` для общей степени.

### Условие является скалярным решением

`if` ожидает одно условие. MATLAB-подобная работа с массивом логических значений требует явного алгоритма над элементами.

### Нет `elseif`

В C++ пишется два слова: `else if`.

### Цепочка сравнений записывается через `&&`

Вместо `0 <= x <= 1` пиши `0 <= x && x <= 1`.

### Точка с запятой не подавляет вывод

В C++ `;` завершает инструкцию. Вывод происходит только по явной команде.

## 16. Разобранный пример 1: классификация измерения

```cpp
#include <iostream>

int main()
{
    double rawValue{0.0};

    std::cout << "Enter raw sensor value: ";
    if (!(std::cin >> rawValue)) {
        std::cerr << "Input must be a number\n";
        return 1;
    }

    const double gain{1.25};
    const double offset{-2.0};
    const double calibrated{rawValue * gain + offset};

    std::cout << "Calibrated value: " << calibrated << '\n';

    if (calibrated < 0.0) {
        std::cout << "State: below range\n";
    } else if (calibrated <= 10.0) {
        std::cout << "State: normal\n";
    } else {
        std::cout << "State: above range\n";
    }

    return 0;
}
```

Разбор:

- `rawValue` должен меняться при чтении, поэтому не является `const`;
- состояние потока проверяется до использования значения;
- коэффициенты объявлены `const`;
- `calibrated` вычисляется один раз и после этого не меняется;
- условия расположены от нижнего диапазона к верхнему;
- во второй ветви уже известно, что значение не меньше нуля, поэтому достаточно проверить верхнюю границу;
- неправильный текстовый ввод завершает программу с кодом `1`.

## 17. Разобранный пример 2: режим и таблица отсчётов

```cpp
#include <iostream>

enum class Waveform {
    constant,
    ramp
};

int main()
{
    const Waveform waveform{Waveform::ramp};
    const int sampleCount{5};
    const double startValue{2.0};
    const double step{0.5};

    switch (waveform) {
    case Waveform::constant:
        std::cout << "constant waveform\n";
        break;
    case Waveform::ramp:
        std::cout << "ramp waveform\n";
        break;
    }

    for (int index{0}; index < sampleCount; ++index) {
        double value{startValue};

        if (waveform == Waveform::ramp) {
            value += static_cast<double>(index) * step;
        }

        std::cout << "sample " << index
                  << ": " << value << '\n';
    }

    return 0;
}
```

Разбор:

- `Waveform` выражает допустимый набор режимов лучше, чем числа `0` и `1`;
- `switch` печатает выбранный режим;
- цикл выполняется ровно пять раз с индексами `0`–`4`;
- `value` создаётся заново на каждой итерации;
- индекс явно преобразуется в `double` для вещественного вычисления;
- в режиме `constant` значение не изменялось бы;
- переменная `index` не существует после цикла.

Оба примера компилируются командой:

```bash
c++ -std=c++20 -Wall -Wextra -Wpedantic example.cpp -o example
```

## 18. Типичные ошибки

### Ошибка 1. Переменная не инициализирована

Всегда задавай начальное значение фундаментальному типу.

### Ошибка 2. Целочисленное деление записано в `double`

`double result = 1 / 2;` даёт `0.0`. Сделай хотя бы один операнд вещественным до деления.

### Ошибка 3. `^` используется для степени

В C++ это XOR. Для квадрата пиши `x * x`.

### Ошибка 4. Присваивание вместо сравнения

`if (value = 5)` меняет значение и затем проверяет результат. Для сравнения нужен `==`. Компилятор может предупредить, но понимать различие обязан ты.

### Ошибка 5. Математическая цепочка сравнений

`0 <= x <= 1` не имеет ожидаемого смысла. Используй два сравнения с `&&`.

### Ошибка 6. `<=` в цикле по количеству

При `index <= count` выполняется `count + 1` итераций. Для диапазона `[0, count)` нужно `<`.

### Ошибка 7. Лишняя `;` после `if` или `for`

Она создаёт пустое тело, а следующий блок выполняется отдельно.

### Ошибка 8. Забытый `break` в `switch`

Выполнение переходит в следующую ветвь. Не допускай это случайно.

### Ошибка 9. Бесконечный `while`

Условие не меняется внутри цикла. Перед запуском назови переменную, которая приближает завершение.

### Ошибка 10. Беззнаковый обратный цикл

Условие вроде `index >= 0` всегда истинно для беззнакового `index`. Не используй такую форму.

### Ошибка 11. Непроверенный ввод

После неудачного `std::cin >> value` нельзя считать, что получено корректное число.

### Ошибка 12. Точное сравнение вычисленных `double`

Многие вещественные результаты имеют малую ошибку округления. Подробное сравнение с допуском появится в численной главе.

1. Классифицируй число как отрицательное, нулевое или положительное.
2. Проверь, входит ли число в закрытый диапазон `[low, high]`.
3. Выведи первые `N` нечётных чисел.
4. Вычисли факториал небольшого неотрицательного `N` циклом и заранее ограничь допустимый диапазон.
5. Создай `enum class Season` и выведи название времени года через `switch`.

Для диапазона нужны два сравнения и `&&`. Первое нечётное число равно `1`, а следующее можно получать прибавлением `2`. Для факториала начальное произведение равно `1`; отдельно подумай о `0!`.

### Уровень 3. Маленькая модель накопления

Напиши консольную программу, которая моделирует накопление значения по шагам.

Входы:

- начальное значение;
- изменение за шаг;
- количество шагов;
- нижняя и верхняя допустимые границы.

Требования:

- проверить успешность числового ввода;
- отклонить отрицательное число шагов;
- отклонить диапазон, у которого нижняя граница больше верхней;
- на каждом шаге вывести индекс и текущее значение;
- классифицировать значение как `below`, `inside` или `above`;
- завершить цикл раньше, если значение вышло за верхнюю границу;
- использовать `const` для параметров, которые после чтения не меняются;
- не использовать массивы и функции: всё упражнение пока может находиться в `main`.

<details>
<summary>Подсказка к уровню 3</summary>

После чтения и проверок создай изменяемую переменную `current`. Цикл начни с индекса `0` или `1`, но письменно определи, означает ли начальное состояние шаг номер ноль. Для раннего завершения после вывода используй `break`.

</details>

## 20. Вопросы для самопроверки

### 1. Может ли переменная C++ изменить свой тип во время жизни?

Нет. После объявления её тип фиксирован.

### 2. Чем `2` отличается от `2.0`?

`2` — целый литерал, `2.0` — вещественный литерал типа `double`.

### 3. Чему равно `1 / 2`?

Нулю, потому что оба операнда целые.

### 4. Сделает ли `double result = 1 / 2` деление вещественным?

Нет. Деление уже выполнено как целое, затем ноль преобразован в `double`.

### 5. Что означает `const` у локальной переменной?

После инициализации значение нельзя изменить обычным присваиванием.

### 6. Убирает ли `auto` статический тип?

Нет. Компилятор выводит конкретный тип из инициализатора.

### 7. Как в C++ записать «x от нуля до единицы включительно»?

`0.0 <= x && x <= 1.0`.

### 8. Чем `&&` отличается от `&`?

`&&` — логическое И с коротким замыканием. `&` обычно является побитовой операцией и вычисляет оба операнда.

### 9. Какие индексы даёт цикл `for (int i{0}; i < 4; ++i)`?

`0`, `1`, `2`, `3`.

### 10. Когда удобен `while`?

Когда число повторений заранее неизвестно и завершение определяется изменяемым условием.

### 11. Зачем нужен `enum class`?

Чтобы выразить ограниченный набор именованных вариантов отдельным безопасным типом.

### 12. Что произойдёт без `break` в ветви `switch`?

Выполнение продолжится в следующей ветви, если не завершится другим способом.

### 13. Почему нужно проверять `std::cin`?

Ввод может не соответствовать ожидаемому типу, и тогда значение нельзя считать полученным корректно.

### 14. Что такое область видимости?

Часть программы, в которой имя доступно.
