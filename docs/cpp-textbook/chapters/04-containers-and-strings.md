# Глава 4. Контейнеры и строки

## Зачем тебе нужна эта тема

Реальные программы редко работают с одним числом. Обычно есть последовательность отсчётов, список имён, набор измерений или фиксированная таблица коэффициентов. В MATLAB почти всё естественным образом становится массивом. В C++ нужно явно выбрать тип хранения.

В этой главе ты познакомишься с тремя основными типами стандартной библиотеки:

- `std::array` — последовательность фиксированного размера;
- `std::vector` — последовательность, размер которой может меняться;
- `std::string` — владеющая последовательность символов для текста.

Эти типы управляют своей памятью сами. На данном этапе тебе не нужны ни `new`, ни `delete`, ни C-массивы. Умение уверенно пользоваться стандартными контейнерами важнее знакомства с ручной памятью.

## Результаты обучения

После главы ты сможешь:

- выбрать между `std::array`, `std::vector` и `std::string`;
- создать контейнер и узнать его размер;
- добавить, удалить и изменить элементы `vector`;
- безопасно обращаться к элементам;
- обойти контейнер диапазонным и индексным циклом;
- отличить `size()` от `capacity()`;
- понять различие `reserve()` и `resize()`;
- передать контейнер в функцию без ненужного копирования;
- прочитать строку целиком с помощью `std::getline`;
- распознать инвалидированную ссылку на элемент `vector`;
- объяснить главные отличия контейнеров C++ от MATLAB-массивов.

## 1. Контейнер владеет элементами

Контейнер — объект, который хранит другие объекты. Например:

```cpp
std::vector<double> temperatures{18.5, 20.0, 21.5};
```

Здесь:

- `std::vector` — тип контейнера;
- `double` — тип каждого элемента;
- `temperatures` владеет своими элементами;
- элементы имеют индексы `0`, `1` и `2`.

Когда `temperatures` уничтожается, его элементы и занятая ими память освобождаются автоматически. Это одна из причин использовать стандартные контейнеры вместо ручного массива.

Контейнер C++ обычно хранит элементы **одного типа**. В `std::vector<double>` нельзя поместить строку. Такая строгость позволяет компилятору обнаруживать ошибки раньше запуска.

## 2. `std::array`: размер известен заранее

`std::array<T, N>` хранит ровно `N` элементов типа `T`:

```cpp
#include <array>

std::array<double, 4> coefficients{0.25, 0.25, 0.25, 0.25};
```

Размер является частью типа. `std::array<double, 4>` и `std::array<double, 8>` — разные типы.

Используй `array`, когда количество элементов известно при компиляции и не меняется по смыслу задачи:

- координаты точки;
- коэффициенты фильтра фиксированного порядка;
- число поднесущих или символов, заданное стандартом;
- маленькая таблица настроек постоянной длины.

Основные операции:

```cpp
coefficients.size();     // 4
coefficients.empty();    // false
coefficients[0];         // первый элемент
coefficients.at(3);      // четвёртый элемент с проверкой границы
coefficients.front();    // первый элемент
coefficients.back();     // последний элемент
```

У `array` нет `push_back`, потому что его размер не меняется.

## 3. `std::vector`: динамический размер

`std::vector<T>` хранит непрерывную последовательность элементов типа `T` и может менять размер во время работы программы:

```cpp
#include <vector>

std::vector<double> samples;
samples.push_back(0.5);
samples.push_back(1.0);
samples.push_back(1.5);
```

После трёх добавлений `samples.size()` равно трём.

Создать вектор можно несколькими способами:

```cpp
std::vector<int> empty;
std::vector<int> values{2, 4, 6};
std::vector<double> zeros(5, 0.0);
std::vector<double> fiveDefaultValues(5);
```

Обрати внимание на разницу:

```cpp
std::vector<int> a{5}; // один элемент со значением 5
std::vector<int> b(5); // пять элементов со значением 0
```

Фигурные и круглые скобки здесь выражают разные намерения.

### Основные операции `vector`

```cpp
values.push_back(8);   // добавить в конец
values.pop_back();     // удалить последний элемент
values.clear();        // удалить все элементы
values.size();         // число элементов
values.empty();        // пуст ли вектор
values.front();        // первый элемент
values.back();         // последний элемент
```

Не вызывай `front`, `back` или `pop_back` для пустого вектора. Сначала проверь `empty()`.

## 4. Индексы и границы

Индексация начинается с нуля:

```cpp
std::vector<int> values{10, 20, 30};

values[0]; // 10
values[1]; // 20
values[2]; // 30
```

Индекс `3` уже находится за границей.

Есть два основных способа доступа:

```cpp
values[1];
values.at(1);
```

`operator[]` не проверяет границу. При неправильном индексе программа получает неопределённое поведение.

`at()` проверяет границу и при ошибке сообщает об исключительной ситуации. В учебных программах и в коде с внешним индексом `at()` часто помогает быстрее обнаружить ошибку.

Однако `at()` не заменяет продуманный контракт. Если индекс пришёл от пользователя, программа должна заранее решить, что считать допустимым вводом.

### Тип размера

`size()` возвращает беззнаковый тип, обычно `std::size_t`:

```cpp
for (std::size_t index{0}; index < values.size(); ++index) {
    std::cout << values[index] << '\n';
}
```

Опасный код:

```cpp
const auto lastIndex = values.size() - 1;
```

Если `values` пуст, вычитание единицы не даст `-1`: беззнаковое значение перейдёт к очень большому числу. Сначала проверяй `empty()` или строй цикл так, чтобы вычитание не требовалось.

## 5. Диапазонный цикл

Если индекс не нужен, диапазонный `for` обычно проще:

```cpp
for (double sample : samples) {
    std::cout << sample << '\n';
}
```

Здесь каждый `sample` копируется. Для одного `double` это нормально.

Чтобы изменить элементы:

```cpp
for (double& sample : samples) {
    sample *= 2.0;
}
```

Чтобы читать крупные объекты без копирования:

```cpp
for (const std::string& name : names) {
    std::cout << name << '\n';
}
```

Выбор похож на параметры функций:

- `T value` — копия элемента;
- `T& value` — можно изменить исходный элемент;
- `const T& value` — чтение исходного элемента без копии.

## 6. `size`, `capacity`, `reserve` и `resize`

У вектора есть размер и ёмкость:

- `size()` — сколько элементов сейчас существует;
- `capacity()` — для скольких элементов уже выделено место без следующего перераспределения памяти.

Когда вектору не хватает ёмкости, он выделяет более крупный блок и переносит туда элементы. Поэтому ёмкость может быть больше размера.

### `reserve`

Если заранее известно примерное количество элементов, можно подготовить память:

```cpp
std::vector<double> samples;
samples.reserve(1000);
```

После этого `samples.size()` всё ещё равен нулю. Элементов пока нет. `reserve` меняет ёмкость, а не размер.

### `resize`

```cpp
samples.resize(1000);
```

Теперь в векторе действительно существует 1000 элементов, и его размер равен 1000.

Типичная ошибка:

```cpp
std::vector<double> values;
values.reserve(10);
values[0] = 1.0; // ошибка: размер всё ещё равен нулю
```

После `reserve` добавляй элементы через `push_back` либо отдельно вызывай `resize`, если тебе действительно нужны существующие элементы.

## 7. Почему ссылки на элементы могут стать недействительными

Рассмотрим код:

```cpp
std::vector<int> values{10, 20};
int& first = values[0];
values.push_back(30);
```

`push_back` может вызвать перераспределение памяти. Тогда старый блок исчезнет, элементы окажутся в новом месте, а ссылка `first` станет недействительной.

После операций, способных изменить память вектора, не используй сохранённые:

- ссылки на элементы;
- указатели на элементы;
- итераторы.

Если ссылка нужна только на короткое время, получай её после завершения добавлений. `reserve` может уменьшить число перераспределений, но логика программы не должна зависеть от случайной текущей ёмкости.

## 8. Передача контейнера в функцию

Если функция только читает вектор, можно принять его по константной ссылке:

```cpp
double sum(const std::vector<double>& values)
{
    double result{0.0};
    for (double value : values) {
        result += value;
    }
    return result;
}
```

Если функция должна изменить тот же вектор:

```cpp
void scale(std::vector<double>& values, double factor)
{
    for (double& value : values) {
        value *= factor;
    }
}
```

Если функция должна создать новый результат, возвращай вектор по значению:

```cpp
std::vector<double> scaled(const std::vector<double>& values, double factor)
{
    std::vector<double> result;
    result.reserve(values.size());

    for (double value : values) {
        result.push_back(value * factor);
    }
    return result;
}
```

Возврат `vector` по значению является нормальным современным C++. Не заменяй его выходным параметром только из страха перед копированием.

## 9. `std::string`: строка, которая владеет текстом

`std::string` хранит последовательность символов и сам управляет памятью:

```cpp
#include <string>

std::string name{"sensor"};
name += "_01";
```

Основные операции:

```cpp
name.size();
name.empty();
name[0];
name.at(0);
name += " suffix";
name.find("sensor");
name.substr(0, 6);
```

Строки можно сравнивать:

```cpp
if (name == "sensor_01") {
    // строки равны
}
```

Сложение создаёт новую строку:

```cpp
const std::string fullName = group + "/" + name;
```

### `std::cin >>` и `std::getline`

Оператор `>>` читает одно слово до пробельного символа:

```cpp
std::cin >> name;
```

`std::getline` читает строку целиком:

```cpp
std::getline(std::cin, name);
```

Если перед `getline` использовался `>>`, во входном потоке может остаться символ новой строки. Его нужно осознанно обработать. Не добавляй случайные повторные `getline`, пока не понял состояние потока.

### Замечание о русском тексте

`std::string::size()` сообщает число хранимых байтов, а не обязательно число видимых пользователю символов. Для английских букв ASCII эти числа совпадают. Для текста в UTF-8 русская буква обычно занимает несколько байтов. Полноценная обработка Unicode — отдельная тема; пока не используй `size()` как надёжное количество русских букв.

## 10. Отличия от MATLAB

### Нет единого универсального массива

В MATLAB обычный массив сразу поддерживает много численных операций. В стандартной библиотеке C++ `vector` — прежде всего контейнер. Выражение `a * 2` не умножает автоматически каждый элемент вектора.

### Индексация начинается с нуля

Первый элемент — `values[0]`, последний при непустом векторе — `values[values.size() - 1]`.

### Нет автоматического расширения через далёкий индекс

В MATLAB присваивание за текущей границей может расширить массив. В C++ запись `values[10] = x` не создаст недостающие элементы. Сначала используй `push_back` или `resize`.

### `vector` не различает строку и столбец

`std::vector<double>` — одномерная последовательность. У неё нет ориентации «строка» или «столбец». Если ориентация важна, её выражают отдельной моделью данных.

### Размер и ёмкость — разные понятия

В MATLAB детали ёмкости обычно скрыты. У `vector` они доступны, потому что повторное выделение памяти влияет на производительность и действительность ссылок.

### Строки имеют явный тип

`std::string` — отдельный тип стандартной библиотеки. Он не является числовым массивом и не смешивается с `vector<double>`.

## 11. Разобранный пример 1: журнал измерений

```cpp
#include <iostream>
#include <vector>

double mean(const std::vector<double>& values)
{
    if (values.empty()) {
        return 0.0;
    }

    double total{0.0};
    for (double value : values) {
        total += value;
    }
    return total / static_cast<double>(values.size());
}

std::vector<double> aboveThreshold(
    const std::vector<double>& values,
    double threshold)
{
    std::vector<double> result;
    result.reserve(values.size());

    for (double value : values) {
        if (value > threshold) {
            result.push_back(value);
        }
    }
    return result;
}

int main()
{
    std::vector<double> measurements{10.0, 12.5, 8.0};
    measurements.push_back(15.5);

    const std::vector<double> high{aboveThreshold(measurements, 11.0)};

    std::cout << "count: " << measurements.size() << '\n';
    std::cout << "mean: " << mean(measurements) << '\n';
    std::cout << "above threshold:";

    for (double value : high) {
        std::cout << ' ' << value;
    }
    std::cout << '\n';
}
```

Разбор:

- оба входных вектора передаются по `const&`, потому что функции только читают их;
- поведение `mean` на пустом входе выбрано явно: вернуть `0.0`; в серьёзной численной библиотеке можно выбрать другой контракт;
- размер приводится к `double`, чтобы деление было вещественным;
- `aboveThreshold` возвращает новый вектор по значению;
- `reserve(values.size())` выделяет достаточно места в худшем случае, но не создаёт элементы;
- элементы добавляются через `push_back`;
- исходный `measurements` не меняется при фильтрации.

## 12. Разобранный пример 2: обработка названий

```cpp
#include <iostream>
#include <string>
#include <vector>

std::string makeFullName(
    const std::string& group,
    const std::string& name)
{
    if (group.empty()) {
        return name;
    }
    return group + "/" + name;
}

void printNames(const std::vector<std::string>& names)
{
    for (const std::string& name : names) {
        std::cout << "- " << name << '\n';
    }
}

int main()
{
    std::vector<std::string> sensors;
    sensors.reserve(3);
    sensors.push_back(makeFullName("lab", "temperature"));
    sensors.push_back(makeFullName("lab", "pressure"));
    sensors.push_back(makeFullName("", "reference"));

    printNames(sensors);

    if (!sensors.empty()) {
        std::cout << "first: " << sensors.front() << '\n';
        std::cout << "last: " << sensors.back() << '\n';
    }
}
```

Разбор:

- `vector<string>` хранит строки и владеет ими;
- функция `makeFullName` читает аргументы по `const&` и возвращает новую строку;
- в диапазонном цикле используется `const std::string&`, чтобы не копировать каждую строку;
- перед `front()` и `back()` проверяется, что вектор не пуст;
- `reserve(3)` подготавливает память, а три элемента всё равно добавляются через `push_back`.

Оба примера можно собрать командой:

```bash
c++ -std=c++20 -Wall -Wextra -Wpedantic example.cpp -o example
```

## 13. Типичные ошибки

### Ошибка 1. Индекс равен размеру

Для размера `N` допустимы индексы от `0` до `N - 1`. Условие цикла обычно должно быть `index < values.size()`, а не `<=`.

### Ошибка 2. Ожидание, что `reserve` создаёт элементы

`reserve` меняет только ёмкость. Индексировать элементы можно лишь в пределах `size()`.

### Ошибка 3. Вызов `back()` у пустого вектора

Сначала проверяй `empty()`.

### Ошибка 4. Сохранённая ссылка после `push_back`

Добавление может перераспределить память и сделать ссылку недействительной.

### Ошибка 5. Копирование в диапазонном цикле

```cpp
for (std::string name : names) {
```

Каждая строка копируется. Если нужно только чтение, используй `const std::string&`.

### Ошибка 6. Вектор передаётся по значению без намерения копировать

Если функция только читает контейнер, чаще нужен `const std::vector<T>&`.

### Ошибка 7. Попытка расширить вектор индексом

`values[10] = x` не меняет размер. Используй `push_back` или заранее `resize`.

### Ошибка 8. Вычитание единицы из нулевого `size()`

`size_t` беззнаковый. Сначала проверь пустоту.

### Ошибка 9. Ожидание автоматических поэлементных операций

`vector` не поддерживает MATLAB-подобное умножение всех элементов одним оператором. Напиши явный цикл или используй подходящий стандартный алгоритм позже.

### Ошибка 10. `std::string::size()` считается числом русских букв

В UTF-8 размер строки в байтах не совпадает с количеством видимых символов.

<summary>Подсказка к уровню 1</summary>

Для чтения элементов подходит `for (double value : values)`. Для изменения нужен `for (double& value : values)`. При вычислении среднего сначала реши, что функция должна делать для пустого контейнера.

</details>

4. Прочитай полное имя пользователя через `getline`, а не одно слово.

<details>
<summary>Подсказка к уровню 2</summary>

Функция-фильтр создаёт пустой результирующий вектор и добавляет подходящие элементы через `push_back`. В `join` не добавляй разделитель после последней строки: можно добавлять его перед каждым элементом, кроме первого.

</details>

### Уровень 3. Небольшой журнал датчиков

Создай программу, хранящую два связанных списка:

- названия датчиков в `std::vector<std::string>`;
- последние измерения в `std::vector<double>`.

Требования:

- размеры списков должны совпадать;
- отдельная функция печатает все пары «название — значение»;
- отдельная функция находит индекс первого датчика с заданным именем;
- отдельная функция возвращает значения выше порога;
- пустой список обрабатывается корректно;
- неправильные несовпадающие размеры не должны приводить к выходу за границу.

После решения ответь: почему два отдельных вектора могут быть неудобны и какой единый тип данных стоило бы создать позднее?

<details>
<summary>Подсказка к уровню 3</summary>

До цикла сравни `names.size()` и `values.size()`. При поиске перебирай индексы от нуля, потому что нужно вернуть позицию. Если имя не найдено, пока можно вернуть `names.size()` как специальное значение, но обязательно документируй это решение. Позднее ты познакомишься с более явным представлением отсутствующего результата.

</details>

## 15. Вопросы для самопроверки

### 1. Когда выбирать `std::array`?

Когда размер известен при компиляции и не должен меняться по смыслу задачи.

### 2. Когда выбирать `std::vector`?

Когда нужна владеющая последовательность, размер которой определяется или меняется во время выполнения.

### 3. Что возвращает `size()`?

Текущее число существующих элементов контейнера.

### 4. Чем `at()` отличается от `operator[]`?

`at()` проверяет границу и сообщает об ошибке, а `operator[]` границу не проверяет.

### 5. Чем `reserve()` отличается от `resize()`?

`reserve` подготавливает ёмкость, но не создаёт элементы. `resize` меняет число существующих элементов.

### 6. Почему ссылка на элемент может стать недействительной после `push_back`?

Вектор может выделить новый блок памяти и перенести туда элементы.

### 7. Как диапазонным циклом изменить исходные элементы?

Использовать изменяемую ссылку: `for (T& value : values)`.

### 8. Как читать строки контейнера без копирования?

Использовать `for (const std::string& text : texts)`.

### 9. Можно ли обратиться к `values[0]` после одного `reserve`, если размер был нулевым?

Нет. `reserve` не создаёт первый элемент.

### 10. Что читает `std::cin >> text`?

Обычно одно слово до пробельного символа. Для всей строки используют `getline`.

### 11. Является ли `std::vector<double>` матрицей?

Нет. Это одномерная последовательность. Размеры и преобразование многомерных индексов нужно моделировать отдельно.

### 12. Почему возвращать `vector` по значению нормально?

Это безопасная семантика владения, а современный C++ и компилятор умеют эффективно передавать такие результаты.
